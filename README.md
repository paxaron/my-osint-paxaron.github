# PAXARON — Telegram Landing Page

Готовая статическая страница с кнопкой перехода на Telegram: **@paxaron**.

## Запуск локально
Просто открой `index.html` в браузере.

## Публикация через GitHub Pages

1. Создай новый репозиторий на GitHub, например `paxaron-telegram`.
2. Загрузи в него `index.html`, `style.css` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Сохрани настройки. GitHub выдаст адрес опубликованного сайта.

## Важно
Сайт не собирает пароли, токены или другие данные посетителей. Кнопка ведёт напрямую на `https://t.me/paxaron`.
